# Bangladesh Documentary Site + AI Chatbot

A full-stack documentary/vlog website about Bangladesh, featuring a
RAG-powered (Retrieval-Augmented Generation) AI chatbot that answers
visitor questions using the site's own content — not generic knowledge.

**100% free to run** — embeddings run locally via `sentence-transformers`,
retrieval is a hand-built NumPy vector store, and the chatbot's answers are
generated by a local LLM via **Ollama**. No API keys, no billing, no cost.

## Tech Stack

- **Frontend:** Next.js (React), plain CSS
- **Backend:** FastAPI (Python)
- **Embeddings:** sentence-transformers (local)
- **Vector search:** Hand-built NumPy vector store (cosine similarity)
- **LLM:** Ollama running Llama 3.2 (local, free, offline-capable)

## How the AI Chatbot Works

1. `ingest.py` reads documentary transcripts, splits them into chunks,
   converts each chunk into a vector ("embedding") using a free local
   model, and saves them into `store.npz` / `store_meta.json` — a
   hand-built vector store using plain NumPy (no external database
   needed, nothing to compile).
2. When a visitor asks a question, `main.py` embeds their question the
   same way, compares it against every stored vector using a dot product
   (cosine similarity), retrieves the top matching chunks, and sends
   those chunks + the question to a local LLM via **Ollama**.
3. The model answers grounded in the retrieved content — reducing
   hallucination compared to a general-purpose chatbot.

## Running Locally

### Prerequisites
- Node.js
- Python 3.12
- [Ollama](https://ollama.com), with a model pulled:
  ```
  ollama pull llama3.2:3b
  ```

### Backend
```
cd backend
python -m venv venv
venv\\Scripts\\activate      # Windows
pip install -r requirements.txt
python ingest.py
uvicorn main:app --reload --port 8000
```

### Frontend
```
cd frontend
npm install
npm run dev
```

Visit `http://localhost:3000`.
